## What it does

`main.ts` (Node 22, stdlib only, no network, fully deterministic) writes one
line — an alien tourist's review of planet Earth — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

> Earth's apex predator apologizes to furniture after bumping into it. I have never felt safer. 5 stars.

## Run

```sh
node main.ts
cat /output/entry.txt
```
